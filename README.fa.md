# ReachDesk

**میز هوشمند تماس و فرصت‌یابی که از سلیقهٔ شما یاد می‌گیرد.** افراد، پست‌ها و آگهی‌ها را رتبه‌بندی می‌کند، برای هرکدام پیام شخصی با اسم طرف می‌نویسد، مسیر «اول کانکت، بعد پیام» را مدیریت می‌کند، و هرجا مبنای تماس داشته باشید ایمیل را خودکار می‌فرستد. روی کامپیوتر خودتان اجرا می‌شود، کلید API لازم ندارد و توکنی مصرف نمی‌کند.

## چه کارهایی می‌کند

- **پیدا کردن:** جستجوهای آمادهٔ لینکدین که خودتان باز می‌کنید، ذخیرهٔ متن انتخابی با یک کلیک، فایل رسمی `Connections.csv`، هر فایل CSV، و آگهی‌های رسمی Greenhouse، Lever، Ashby و Arbeitnow
- **فهمیدن:** اسم کوچک را استخراج می‌کند و اگر مطمئن نباشد به‌جای حدس زدن «Hello» می‌نویسد. «کامنت بگذارید»، «دایرکت بدهید»، «رزومه بفرستید» و «استخدام می‌کنیم» را به انگلیسی، فرانسوی و فارسی تشخیص می‌دهد
- **ذخیرهٔ پست‌ها:** پست‌هایی که کامنت یا دایرکت می‌خواهند نگه داشته می‌شوند تا خودتان بررسی و انجام دهید
- **یادگیری:** به هر مورد ۱ تا ۵ ستاره و دلیل بدهید. مدل محلی همه‌چیز را دوباره رتبه‌بندی می‌کند. اگر دلیل «مکان اشتباه» باشد، مهارت‌های شما جریمه نمی‌شوند
- **اول کانکت:** برای افراد ناآشنا یادداشت کوتاه بدون لینک آماده می‌شود و بعد از قبول، پیام اصلی خودکار ساخته می‌شود
- **ارسال:** ایمیل برای افرادی که مبنای تماس ثبت‌شده دارند **خودکار** می‌رود. در لینکدین برای هر نفر **یک کلیک**: متن کپی و پروفایل باز می‌شود و دکمهٔ ارسال را خودتان می‌زنید
- **حفاظت:** سقف روزانه، فاصلهٔ ۹۰ روزه بین کمپین‌ها، لغو دائمی تماس و حذف اطلاعات

## چرا ارسال در لینکدین خودکار نیست

[قوانین لینکدین](https://www.linkedin.com/help/linkedin/answer/a1341387) نرم‌افزارهای خودکارسازی و اسکرپ را ممنوع کرده و حساب‌هایی که از آن‌ها استفاده کنند محدود می‌شوند. برای همین در این پروژه کراولر، ارسال خودکار و دور زدن تشخیص ربات وجود ندارد. این تصمیمی عمدی است و جزئیاتش در [سند قوانین](docs/COMPLIANCE.md) آمده است.

## شروع سریع

به Python نسخهٔ ۳٫۱۰ یا بالاتر نیاز دارید و چیز دیگری لازم نیست.

</div>

```bash
python run.py serve
```

<div dir="rtl">

سپس <http://127.0.0.1:8765/> را باز کنید. دکمهٔ «فارسی» در بالای صفحه زبان را عوض می‌کند.

۱. در **تنظیمات**، وبسایت، نام و راه تماس فرستنده را وارد کنید. تا وارد نشوند پیام‌ها مسدود می‌مانند.
۲. در **جستجو** یک جستجو را باز کنید و نتیجه‌ها را از بخش **افزودن** وارد کنید.
۳. در **امروز** دکمهٔ «آماده‌سازی پیام‌های امروز» را بزنید و فهرست را جلو ببرید.
۴. به موردها ستاره بدهید. بعد از حدود ده امتیاز متنوع، رتبه‌بندی سلیقهٔ شما را یاد می‌گیرد.
