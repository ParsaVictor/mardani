# Code of conduct

Be respectful in issues, pull requests and every other project space. Criticize ideas and code, not people.

Harassment, personal attacks, discrimination and publishing someone's private information are not accepted. Neither is using this project's spaces to promote spam or platform-rule evasion.

The maintainer may edit or remove content, and may block anyone who breaks these rules. To report a problem privately, use the contact details on the [maintainer's GitHub profile](https://github.com/ParsaVictor).
